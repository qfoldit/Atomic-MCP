# qFoldIT Integration Status

Atomic-MCP is a **materials/atomistic scientific adapter**.

```text
Atomic-MCP
    ↓
Atomistic / materials capability
    ↓
Scientific Object + Mission Contract
    ↓
Scientific Action Envelope
    ↓
UAG / Runtime
    ↓
Validation + Evidence
```

Shared orchestration, mission semantics and provenance belong to the canonical Rust `qfoldit-core` maintained by `UEFN-QFOLDIT`.

This repository should remain focused on atomistic workflows, structure generation, optimization, molecular dynamics and analysis. It must not become a second qFoldIT control plane.

Preserve all upstream license and attribution requirements.
