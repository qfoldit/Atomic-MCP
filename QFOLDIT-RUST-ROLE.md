# qFoldIT Rust Boundary

## Status

Canonical atomistic/scientific capability boundary. `UEFN-QFOLDIT` / `qfoldit-core` owns mission, policy, provenance and orchestration semantics.

## Rule

Substantive atomic/materials capability may remain here, but no second qFoldIT runtime authority may be introduced.

qFoldIT integrations MUST cross a versioned Rust contract with explicit object identity, hashes, engine/provider provenance and validation state.

## Retirement condition

Absorb only after a Rust replacement demonstrates scientific parity and provenance preservation.
